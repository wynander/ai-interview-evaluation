# Agent Improvement — Take-Home

Pick **one** track and do it. Both are equivalent assessments — same
architecture, same builds, same grading bar. Choose the stack you're
strongest in.

- [`python/`](python/) — Python track (`uv`, LangChain). Start with
  [`python/INSTRUCTIONS.md`](python/INSTRUCTIONS.md).
- [`typescript/`](typescript/) — TypeScript track (`npm`, Next.js, AI SDK).
  Start with [`typescript/INSTRUCTIONS.md`](typescript/INSTRUCTIONS.md).

Do not do both. Do not open a branch or PR on this repo — submit a zip
per your track's instructions.
